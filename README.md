## Цель и задачи системы

### Цель
Создание работоспособного веб-приложения на базе NestJS и React/Vue для взаимодействия учителей, учеников и родителей в рамках контроля учебного процесса.

### Задачи
- Реализовать ролевую модель доступа к системе (Учитель, Ученик, Родитель).
- Спроектировать базу данных (PostgreSQL / MySQL) с использованием ORM, включающую не менее пяти связанных таблиц (пользователи, классы, ученики, предметы, оценки, пропуски).
- Разработать серверную часть (REST API на NestJS) и клиентскую часть (SPA на React или Vue) с использованием TypeScript.
- Реализовать полный CRUD (создание, просмотр, изменение, удаление) для основных сущностей системы.
- Реализовать интерфейс учителя для работы со своими классами и предметами (выставление оценок, отметка пропусков).
- Обеспечить автоматический расчет среднего балла по предметам (ключевая функция).
- Разработать функционал формирования наглядного отчета об успеваемости для родителей.
- Обеспечить безопасную аутентификацию и авторизацию пользователей (JWT-токены, хеширование паролей).
- Реализовать поиск, фильтрацию и постраничный вывод (пагинацию) в списках (например, список учеников или предметов).
- Добавить возможность загрузки файлов (например, фото профиля) с проверкой типа и размера.
- Настроить проверку типов, линтер без ошибок и единую обработку ошибок с понятными сообщениями.
- Подготовить документацию API с помощью Swagger и коллекцию Postman с автотестами.

## Целевая аудитория
- **Учителя** — нуждаются в быстром и удобном инструменте для выставления оценок, фиксации пропусков и работе строго со своими закрепленными классами/предметами.
- **Ученики** — заинтересованы в прозрачном отображении своих оценок, среднего балла и посещаемости.
- **Родители** — хотят получать актуальную сводку и отчет об успеваемости своего ребенка без необходимости прямого контакта со школой по каждому вопросу.

---

## Содержание сайта (основные экраны)
- **Страница авторизации** — вход в систему с распределением прав доступа в зависимости от роли.
- **Рабочая панель учителя** — выбор класса и предмета, интерактивная таблица (журнал) для выставления оценок и отметки пропусков.
- **Личный кабинет ученика** — список изучаемых предметов, полученные оценки, пропуски и текущий средний балл.
- **Личный кабинет родителя** — привязка к профилю ребенка, сводная таблица успеваемости и отчет по среднему баллу.
- **Кастомные страницы ошибок** — шаблоны 403 (нет доступа), 404, 500.

## Функциональные возможности
- Разграничение прав доступа: учитель видит только свои предметы, родитель — только своего ребенка.
- Полный цикл управления данными (CRUD) для классов, предметов, учеников и оценок.
- Добавление и редактирование оценок и пропусков в режиме реального времени.
- Автоматический расчет среднего балла ученика по каждому предмету и общая статистика.
- Формирование отчета об успеваемости в кабинете родителя.
- Поиск, применение фильтров и пагинация в табличных списках.
- Загрузка файлов (изображений) с валидацией формата и размера на сервере.
- Взаимодействие фронтенда с сервером через REST API (NestJS) в асинхронном режиме без перезагрузки страницы.
- Работа с базой данных через ORM (хранение пользователей, классов, предметов, журнала оценок).
- Защита маршрутов (Guards) и строгая валидация передаваемых данных (DTO) как на стороне сервера, так и на стороне клиента.
- Документированный REST API (Swagger) и покрытые автотестами эндпоинты (Postman).
